# Наши первые два месяца

Отдельный небольшой сайт в формате интерактивного альбома: ваша история, редактируемый мини-тест из пяти вопросов и галерея фотографий. Это новая концепция, она не меняет `love-universe`.

## Запуск

Открой `index.html` двойным щелчком для просмотра или запусти папку через Live Server в VS Code. Чтобы отправлять результаты теста на почту, нужен Live Server либо опубликованный сайт (`http://` или `https://`). Сборка и установка пакетов не нужны. Google Fonts подгружаются при наличии интернета; без сети остаются запасные системные шрифты.

## Как это работает

- Нажми один из трёх вариантов, а после каждого вопроса — «Проверить ответ».
- В раскрывающемся блоке теста можно изменить текст вопросов, все варианты и правильный ответ. Нажми «Сохранить тест», затем «Скопировать ссылку для неё»: ссылка содержит настройки, поэтому тест откроется с твоими правками и на другом телефоне. Локальная копия также сохраняется в этом браузере.
- По завершении теста можно отправить счёт и выбранные ответы на `dimabora824@gmail.com` через FormSubmit; для этого нужна галочка согласия. FormSubmit хранит отправки до 30 дней.
- Либо скопировать результат и вручную отправить его в Telegram.
- При первой отправке FormSubmit пришлёт владельцу адреса письмо для активации формы; после нажатия ссылки ответы начнут приходить на почту. Проверь также папку «Спам».
- Форму нельзя проверить, открыв файл напрямую как `file://`: опубликуй сайт или запусти его через локальный веб-сервер. Ответы предназначены для сайта, открытого с `http://` или `https://`.
- В истории указано, что вы начали общаться примерно 24–25 августа 2026 года, а встречаться — 12 сентября. Текст написан от первого лица. Его и подписи можно менять в `index.html`; вопросы и ключи по умолчанию — в `script.js`.
- Из выбранных фотографий собран альбом в `assets/gallery-*.jpg`. Перед публикацией фотографии станут доступны посетителям сайта.
